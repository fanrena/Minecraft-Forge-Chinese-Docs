# 文档
这是 MinecraftForge 的官方文档，位于 https://docs.minecraftforge.net。

本文档旨在提供 Forge 开发概念的详细说明，不包含 javadoc。

目标是创建一个经过整理的、关于使用 Forge 开发模组的**权威**文档来源。这不是 Java 语言教程，Java 基础知识不应包含在本文档中。相比过多的示例代码，更倾向于提供详尽的解释说明。

欢迎提交与 Forge 开发文档相关的 Pull Request。详见 [CONTRIBUTING.md](/CONTRIBUTING.md)。

虽然我们会尽快修正严重错误，但不要期望本文档会持续频繁更新。
