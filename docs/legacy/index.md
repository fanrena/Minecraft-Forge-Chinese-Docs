旧版本文档
=================================

Forge 使用 LTS 系统，只有最新版本和当前 LTS 版本有易访问的文档。旧版本文档仅供参考。

!!! important
    旧版本文档仅供参考。不要在 Forge Discord 或论坛上寻求旧版本帮助，**你不会得到支持。**

### RetroGradle
一项归档计划，将旧版 ForgeGradle 1.x 工具链升级到现代 ForgeGradle 4.x+，以保留所有历史版本的 Minecraft Forge。仅用于**保存**，不用于开发旧版本模组。
