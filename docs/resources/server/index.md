数据包
=========

自 1.13 起，Mojang 在原版游戏中添加了[数据包][datapack]。数据包通过 `data` 目录修改逻辑服务器的文件，包括进度、战利品表、结构、配方、标签等。

数据包存储在项目的 `resources` 目录中的 `data` 文件夹内。模组可以有多个数据域。

详见 [Minecraft Wiki 数据包教程][createdatapack]。
